# Export & reset

The <code>⋮</code> panel has four buttons:

| Button | Downloads / does |
|---|---|
| **⬇ MIDI** | `tune_title.mid` — with the current transposition, swing, chords on/off, metronome, count-in and muted voices |
| **⬇ ABC** | `tune_title.abc` — the current tune, **with your edits** |
| **⬇ Whole tunebook** | `first_title_recueil.abc` — every tune with your edits and the shared header (only shown for tunebooks) |
| **↺ Reset** | restores the original text of the current tune and the default settings |
