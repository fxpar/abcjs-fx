# Export et réinitialisation

Le panneau <code>⋮</code> propose quatre boutons :

| Bouton | Télécharge / fait |
|---|---|
| **⬇ MIDI** | `titre_du_morceau.mid` — avec la transposition, le swing, les accords, le métronome, le décompte et les voix coupées en cours |
| **⬇ ABC** | `titre_du_morceau.abc` — le morceau courant, **avec vos modifications** |
| **⬇ Recueil complet** | `premier_titre_recueil.abc` — tous les morceaux modifiés et l'en-tête commun (affiché seulement pour un recueil) |
| **↺ Réinitialiser** | rétablit le texte d'origine du morceau courant et les réglages par défaut |
